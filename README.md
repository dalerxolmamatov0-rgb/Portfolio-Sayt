# 🚀 Zamonaviy & Professional Portfolio Sayt

Ushbu loyiha dasturchi, dizayner yoki IT mutaxassisi uchun mo'ljallangan zamonaviy, tezkor, responsiv va interaktiv shaxsiy portfolio veb-saytidir.

---

## 🌟 Asosiy Imkoniyatlari

- 🌗 **Dark / Light mavzu almashtirgich**: Foydalanuvchi tanlovi `localStorage` da avtomatik saqlanadi.
- 🎨 **Glassmorphism & Neon Dizayn**: Zamonaviy oyna effekti, neon jilolar va silliq soyalar.
- ✨ **Interaktiv Canvas foni**: Sichqoncha harakatiga sezgir zarrachalar va yulduzlar animatsiyasi.
- ✍️ **Typewriter (Yozuv terish) effekti**: Mutaxassislik sohalari dinamik o'zgaradi.
- 📊 **Statistika hisoblagichlari**: Sahifa ochilganda 0 dan ko'tariluvchi silliq hisoblagichlar.
- 🛠️ **Ko'nikmalar (Skills) foizli progress barlar**: Animatsiyali ko'nikma ko'rsatkichlari.
- ⏳ **Interaktiv Xronologiya (Timeline)**: "Ish tajribasi" va "Ta'lim/Sertifikatlar" tablari.
- 💻 **Filterlanadigan Loyihalar Galereyasi**: Web saytlar, Web ilovalar, Telegram botlar va UI/UX toifalariga ajratilgan.
- 🔍 **Loyihalar haqida Batafsil Modal oyna**: Har bir loyihaning to'liq tavsifi, texnologiyalari va havola tugmalari.
- 📨 **Aloqa formasi**: Validatsiya va yuborish simulyatsiyasi (muvaffaqiyatli xabarnoma bilan).
- 📱 **100% Responsiv**: Smartfon, planshet, noutbuk va katta monitorlarga to'liq moslashgan.

---

## 📂 Fayllar Strukturasi

```
Portfolio sayt/
├── index.html        # Asosiy HTML5 semantik sahifa
├── style.css         # Barcha CSS stillari (O'zgaruvchilar, responsivlik, animatsiyalar)
├── script.js         # Interaktiv funksiyalar (Canvas, filtrlash, mavzular, modal)
└── README.md         # Loyiha qo'llanmasi
```

---

## 🛠️ Qanday sozlash (O'zgartirish) mumkin?

1. **Shaxsiy ma'lumotlarni o'zgartirish:**
   - `index.html` faylini oching va ism-familiya, email, telefon, ijtimoiy tarmoqlar havolalarini (`github.com`, `t.me`, `linkedin.com`) o'zingiznikiga almashtiring.
2. **Loyihalarni qo'shish yoki tahrirlash:**
   - `script.js` faylidagi `projectsData` obyektidan loyihalar nomlari, tavsiflari va havolalarini tahrirlang.
3. **Saytni internetga bepul joylash (Deploy):**
   - **GitHub Pages**: Ushbu kodni GitHub repository'ga yuklang va `Settings -> Pages` bo'limidan ishga tushiring.
   - **Vercel** yoki **Netlify**: Loyiha papkasini to'g'ridan-to'g'ri tortib tashlab (Drag & Drop) 1 daqiqada bepul jonli veb-saytga aylantiring.

---

## ⚡ Ishga tushirish

Fayllarni ishga tushirish uchun `index.html` faylini istalgan brauzerda (Chrome, Edge, Firefox, Safari) ochish kifoya. Hech qanday qo'shimcha o'rnatish talab etilmaydi!
